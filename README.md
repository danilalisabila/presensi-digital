# Presensi Korlap Sholat Jama'ah

Aplikasi web pencatatan absensi harian untuk tim **Koordinator Lapangan (Korlap) Sholat Jama'ah** Pondok Putra - Yayasan Pondok Pesantren Salafiyah Al-Falah Putak.

Mendukung 5 waktu sholat:
1. **Shubuh** (Koordinator: *Petugas Jaga Malam*)
2. **Dhuhur** (Koordinator: *Ust. Rabil Afraja + Guru Piket*)
3. **Ashar** (Koordinator: *Ust. Robbul Insan*)
4. **Magrib** (Koordinator: *Ust. Muhammad Sendi*)
5. **Isya** (Koordinator: *Ust. Muhammad Sendi*)

Dibangun menggunakan **React + Vite** untuk antarmuka pengguna (*mobile-friendly*) dan **Google Apps Script (GAS) + Google Sheets** sebagai database & API backend tanpa biaya server (*serverless & free*).
